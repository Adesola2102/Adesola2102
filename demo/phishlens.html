PhishLens
a phishing checker that explains itself in plain English
In-browser demo of the translation-layer system built for Zulikhat Adesola Adeyanju’s MIT project at Miva Open University — the full research system (exact SHAP + LIME, 300-tree classifiers) lives in the Python codebase.

Paste an email or a web link below. PhishLens will tell you whether it looks like phishing or legitimate, and — unlike most security tools — explain why in one plain sentence instead of a wall of statistics.

Nothing is sent anywhere — this runs entirely in your browser.

Each bar is how much that feature pushed the decision toward phishing (right, red) or legitimate (left, green), computed from the actual decision paths taken through the trained forest — a fast, in-browser relative of SHAP.

This demo runs a lighter, browser-sized version of the real classifiers (…) trained on the same data described in Chapter Four of the project report. It uses real trained decision trees and the exact same plain-language phrase engine as the full system — only the depth/size of the forest and the attribution method are simplified for speed and portability. No data you type here ever leaves your device.
